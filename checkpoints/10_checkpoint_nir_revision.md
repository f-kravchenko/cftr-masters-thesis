# Чекпоинт 10. Ревизия по итогам встречи с научруком (09.11.2026)

Ответ на 5 пожеланий. Всё ниже зафиксировано и внесено в презентацию и литобзор.

## 1. Формулировки (короткие, без дублей)

- **Проблема (научная):** опубликованные readthrough-модели валидируются на случайных сплитах и предсказывают только репортерный RT — их переносимость на новые варианты, гены и препараты не доказана.
- **Проблема (практическая):** пары «мутация × препарат» невозможно перебрать экспериментально (репортеры и органоиды дороги, плохо масштабируются); без дешёвого приоритизатора новая волна readthrough-терапий повторит провал ataluren.
- **Исследовательский вопрос:** насколько точно ответ пары «нонсенс-вариант × readthrough-препарат» предсказуем из последовательности и формализуемых свойств препарата — и переносится ли предсказание на варианты, гены и препараты, отсутствовавшие в обучении?
- **Актуальность (масштаб):** нонсенс-мутацию несёт хотя бы одна аллель у ~10% пациентов МВ (≈5,5–5,7 тыс. Европа при регистре ECFSPR 57 288 за 2024; ≈400–450 РФ при регистре 4 355 за 2024); модуляторы на нонсенс-аллель не действуют, при двух нонсенс-аллелях (~1%) терапии нет вовсе; следующей волнe препаратов нужен инструмент отбора когорт.
- **Новизна (vs опубликованных):** первая оценка обобщающей способности readthrough-моделей (честные сплиты, бейзлайны, шумовой потолок) + протокол приоритизации пар для CFTR, валидированный на трёх независимых системах; показано, что 0.65–0.86 из R²=0.94 SOTA — артефакт сплита.

## 2. Биологический контекст и схема

Порядок изложения (слайды 2–3 презентации): муковисцидоз как генетическое заболевание → у ~10% пациентов причина — нонсенс-мутации (преждевременный стоп-кодон, PTC) → принцип readthrough-терапии → практическая проблема (зависимость эффекта от мутации и препарата; эксперимент дорог) → DS-задача: не заменять эксперимент, а приоритизировать пары для проверки.
Схема «мРНК → рибосома → PTC → препарат → проскок → полноформатный белок (с оговоркой про вставку аминокислоты)»: `results/pres/fig_scheme.png` (скрипт `make_scheme.py`).

## 3. Препараты: идентичность и механизмы

Полный разбор — `literature/26_drugs.md` (все расшифровки верифицированы по полному тексту Toledano). Суть:

| Кластер (MOA) | Препараты | Где действует |
|---|---|---|
| Аминогликозиды | гентамицин, G418, ELX-02 | рибосома (декодирующий центр) |
| Нуклеозидные аналоги в мРНК | clitocine, 5-FUr | встраиваются в мРНК/стоп-кодон |
| Модификация тРНК | DAP (2,6-диаминопурин) | FTSJ1 → tRNA^Trp, UGA-специфичен |
| Деградеры терминации | SRI-41315 (eRF1), SJ6986 и CC-90009 (eRF3a/GSPT1) | факторы терминации |

Вывод для ML: объединять классы в одной задаче корректно **только с признаками препарата** (межклассовые корреляции RT 0.39 против 0.93 внутри MOA). Конфаунды: clitocine стабилизирует РНК; CC-90009 подавляет NMD (отдельный канал для композиции); ataluren вне восьмёрки, мишень не установлена, активность оспорена.

## 4. Гипотезы: одна главная + две частные, фальсифицируемые

**Главная H.** Ответ пары (вариант, препарат) предсказуем из локального контекста PTC и признаков препарата, и предсказание переносится на невидимое.
- Критерии (a priori): (а) CFTR-holdout Spearman ≥ 0.55 **и** top-1 выбора препарата ≥ 55%; (б) few-shot LODO ≥ 75% потолка (≥ 0.47). Опровержение — провал любого порога на финальном протоколе.
- Текущий статус: (а) 0.62–0.64 и 59% ✓; (б) 0.518 ✓.

**Частная H1 (композиция).** Для эндогенного исхода RT недостаточно: количественная NMD-ось добавляет ≥ +0.2 Spearman к согласованию с органоидным ответом. Опровержение: прирост < +0.1. Статус: ждём скоры NMDetective-AI (GTX 1660, чекпоинт 09).

**Частная H2 (zero-shot препарат).** Молекулярные дескрипторы (SMILES → RDKit) дают zero-shot LODO ≥ 0.8× профильного few-shot (≥ 0.42).
*Проверено 13.11.2026* (`pipeline/lodo_chem.py`, SMILES всех 10 соединений верифицированы через PubChem): без единого измерения нового препарата — **mean Spearman 0.142** — порог 0.42 НЕ достигнут (формально серая зона ≥0.1). Диагноз: при 7 обучающих препаратах 11 дескрипторов недоопределены — модель не может выучить «химия → эффект»; профиль few-shot (0.518), привязанный к 300 калибровочным измерениям, остаётся рабочим способом описания нового препарата. Путь улучшения: фингерпринты/GNN + MOA-класс, но фундаментальное ограничение — n=7 препаратов. Попутно: дескрипторы ataluren/ELX-02 посчитаны и лежат в data/drug_descriptors.csv для каталога.

Понижены из гипотез (по замечанию об избыточности): старая H1 «расширенный контекст бьёт линейную» → методическая проверка внутри протокола (факты: почти нет, enet 0.707 ≈ бустинг 0.704–0.713); старая H5 «вставка аминокислоты» → второй фронт с проверенной пустой нишей: сквозной модели «препарат → вставка → фолдинг» не существует (литобзор 28_insertion_folding.md, 13.11.2026); у CFTR уникально есть готовый датасет валидации — измеренные пары «вставка → фенотип» (Premchandar 2024: G542X→Cys 65–70%/Arg/Trp с разными дефектами фолдинга; Thrasher 2026: 6 PTC; Chen 2023: G550W суперфункционален).
