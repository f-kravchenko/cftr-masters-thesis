# Чекпоинт 1. Валидация темы (27.09.2026)

**Тема:** in silico-стратификация нонсенс-вариантов CFTR для readthrough-терапии.
Полная версия — `cftr-ml-thesis-topics.md`, раздел 7.

## Вердикт deep research (4 потока, сентябрь 2026)

Тема валидна. Ядро «drug-aware DL на данных Toledano» занято preprint'ом **TransStop** (2025, R²=0.94), но TransStop проверялся только на случайном сплите: CFTR in-silico, без переноса, без NMD, без белковых признаков. Клинический разрыв доказан: ataluren и ELX-02 провалились из-за набора пациентов «всех подряд»; активных readthrough-испытаний при CF нет; ~10% пациентов (≈5–7 тыс. в Европе, ≈400–450 в РФ) модуляторами не покрыть принципиально.

## Конкуренты одной таблицей

| Работа | Сделала | Не сделала |
|---|---|---|
| Toledano 2024 (Nat Genet) | датасет 5 871 PTC × 8 препаратов + elastic net | линейность, нет NMD/белка, один репортер |
| TransStop (bioRxiv 2025) | трансформер + drug embeddings, R²=0.94 | честный сплит, CFTR-валидация, NMD, PLM; не рецензирован |
| Mangkalaphiban 2024 | RF, 13 CFTR PTC, G418 | один препарат, мало данных, не decision-tool |
| NMDetective-AI / predNMD (2026) | открытые NMD-скоры для всех PTC | не соединены с readthrough никем |
| HIT-CF / Destoop 2026 | 206 органоидов × ELX-02 | лабораторный отбор: биопсия, недели, дорого |

## Открытые ниши (= наша постановка)

1. Перенос на невидимые гены/варианты — leave-one-gene-out + внешняя CFTR-валидация.
2. Zero-shot на невидимый препарат — leave-one-drug-out (ataluren в данных нет → чистый тест).
3. Композитная модель `RT × NMD-escape` → ожидаемый выход белка. ⚠️ риск: Supek/Lehner владеют обеими половинами.
4. Предсказание вставляемой аминокислоты — модели не существует вовсе (данных мало, второй фронт).

## Постановка

- **Вход:** контекст PTC (±10–72 нт), препарат, NMD-скоры, белковые признаки (домен, PLM).
- **Выход:** (1) `RT(вариант, препарат)`, % от WT; (2) `E[белок] ≈ RT × NMD-escape`; (3) открытый каталог 853 ClinVar CFTR-нонсенс-вариантов × препараты, с неопределённостью.
- **Экзамены:** 10× CV (сравнимость) → leave-one-gene-out (главный) → leave-one-drug-out (8 прогонов) → внешняя валидация (Mangkalaphiban 13 PTC; Thrasher 6 PTC; Destoop органоиды).
- **Метрики:** Spearman ρ, RMSE по log(RT), top-1/2 выбора препарата, калибровка на пороге RT>2%.
- **Бейзлайны:** правила (+4 nt/тип стопа) → elastic net (reimpl.) → бустинг + NMD → TransStop (reimpl.).

## Гипотезы

- **H1.** На leave-one-gene-out расширенный контекст бьёт elastic net (TransStop показывал это только на случайном сплите).
- **H2.** Drug-эмбеддинги дают zero-shot перенос на невидимый препарат (LODO).
- **H3.** Геномная модель ранжирует CFTR-варианты (76 + 13 + 6 внешних) не хуже CFTR-only.
- **H4.** NMD-скоры улучшают предсказание эндогенного ответа, но не репортерного RT.
- **H5.** Вставляемая аминокислота предсказуема из контекста (опционально, данных мало).

## Новизна (для автореферата)

1. Первая оценка обобщающей способности readthrough-моделей (невидимые гены/препараты).
2. Первая композитная модель выхода белка RT × NMD.
3. Первый валидированный CFTR-каталог для отбора когорт (артефакт).

**Не заявлять:** drug-aware DL на Toledano (TransStop), сам датасет, биологию контекста, NMD-предикторы (чужие — наш вклад join + проверка).

## Риски

1. Supek/Lehner объединят свои половины → фокус на CFTR-валидацию и артефакт, писать быстро.
2. TransStop невоспроизводим → сам факт невоспроизведения — результат.
3. Органоиды Destoop «по запросу» → fallback: Mangkalaphiban + Thrasher.
