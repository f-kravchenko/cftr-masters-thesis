# Чекпоинт 4. Воспроизведение TransStop (02.10.2026)

Артефакты: `pipeline/transstop_repro.py`, `results/metrics_transstop.csv`, `results/summary_transstop.md`, venv `.venv-ts` (transformers 4.51.2 — их пин).

## Что сделано

Полное воспроизведение из открытых артефактов: их фильтр данных (rep2, reads>15, не-viral → 48 387 строк), их сплит (random 10%, seed 42, stratify=drug), их веса с HF (NT v2 500M + cross-attention, head 768, drug_embed 64), их метрика (R² на expm1-шкале, clip 0). Неизвестный из репо обучавшийся контекст найден пилотом (6×400 строк): **seq_context_12 (6 нт–стоп–6 нт)**, R² на пилоте 0.95 против 0.2–0.4 у остальных.

## Интерпретация (осторожно!)

1. **CFTR у TransStop — не перенос, а память:** их сплит случайный, CFTR-строки были в train. R²=0.96 на CFTR показывает, что модель плотно запоминает тренировочные гены. Честный перенос (etrain без CFTR) у них не оценён и не может быть оценён без полного переобучения (500M fine-tune).
2. **Сравнение с нашими моделями некорректно напрямую:** наши 0.614–0.630 Spearman / top-1 59% получены при CFTR, полностью исключённом из обучения. Для равного сравнения нужно переобучить TransStop без CFTR — дорого (MPS, часы); кандидаты на этап 3 при наличии GPU.
3. **Главный содержательный вывод:** трансформер на 500M параметров с cross-attention **сам выбрал окно ±6 нт** (context_12) как оптимум — ровно тот локальный сигнал, что в линейной модели Toledano (±3 нт) и в нашем enet. Гигантская модель сошлась к той же биологии: доминирует близкий контекст стоп-кодона. Это усиливает наш вывод о локальности сигнала и ставит вопрос цены: 500M-модель против one-hot регрессии на одном и том же окне (разрыв 0.71 vs 0.94 на случайном сплите — частично память генов).
4. Технически: их remote-код несовместим с transformers 5.x (is_decoder, find_pruneable_heads) — зафиксировано venv'ом с их пином 4.51.2.
