# Каталог readthrough для нонсенс-вариантов CFTR (панель ClinVar)

Модель: elastic net на типе стоп-кодона и ±3 нт (как enet_tuned), отдельная по каждому из 8 препаратов, обучена на данных Toledano 2024 без CFTR-вариантов. Признаки построены из записей c. в названиях вариантов и транскрипта NM_000492.4 (RefSeq, MANE Select). Предсказывается репортёрный readthrough (%). `unseen_fields` — сколько из трёх признаков варианта не встречались в обучении (0–3).

**Самопроверка признаков:** контекст и тип стопа, восстановленные из транскрипта и аллелей, совпали с таблицей Toledano для 76 из 76 измеренных CFTR-вариантов.

**Точность той же модели на 76 измеренных вариантах (они не входили в обучение):** Spearman 0.614; RMSE 0.173 log10; лучший препарат совпал с измеренным в 49% случаев, вошёл в топ-2 — в 74% (на тех же строках правило «всегда DAP» даёт 48%, пара «DAP или SJ6986» — 66%). Измерения Toledano сопоставлены по белковой замене.

**Состав:** 313 строк каталога: 96 с измерениями (76 вариантов) и 217 новых (199 вариантов); у 0 новых строк какой-то из признаков не встречался в обучении.

## Ограничения

- Предсказывается readthrough в репортёрной системе (HEK293T, sort-seq); это не клинический ответ: на органоидах (Destoop 2026, 7 вариантов) репортёрный readthrough не предсказал ответ (−0.22).
- Только 8 препаратов из набора данных; ataluren и ELX-02 в данных отсутствуют.
- Выбор препарата линейная модель почти не улучшает: лучший препарат совпадает с измеренным в 49% против 48% у правила «всегда DAP» (у бустинга с расширенными признаками было 59% против 43%). Каталог ранжирует варианты; из препаратов он скорее сужает выбор до двух (74% против 66%).
- Точность ограничена: Spearman ≈ 0.61, типичная ошибка — примерно вдвое. Это ранжирование для экспериментальной проверки, а не прогноз для пациента.
- 199 новых вариантов не имеют измерений; интервал — это ±1.96·RMSE модели на отложенном CFTR.
