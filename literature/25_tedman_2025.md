# Tedman, Schlebach et al., 2025 — DMS 232 CFTR-вариантов ± корректоры при нокауте кальнексина

**Ссылка/DOI:** [eLife 14:RP107180](https://elifesciences.org/articles/107180) · PMID 41379933 · [bioRxiv 2025.04.03.647093](https://www.biorxiv.org/content/10.1101/2025.04.03.647093v1) · **Статус:** рецензирована (eLife, Reviewed Preprint) · **Роль для нас:** продолжение DMS-серии Schlebachа (бонус-ось); пример вариант-специфичного клеточного контекста

## Библиография (для списка литературы)

Tedman, Schlebach et al. // eLife, 2025; 14:RP107180. PMID 41379933.

## Что сделано (методы, датасет)

- **DMS-библиотека из 232 CF-вариантов** в клетках с **CRISPR-нокаутом кальнексина (CANX)**.
- Условия: **± 3 мкМ VX-445 + 3 мкМ VX-661** (элексакафтор + тезакафтор).
- Рид-аут — тот же, что в серии лаборатории Schlebachа: плазматическая мембранная экспрессия (PME) через флуоресцентную сортировку.

## Ключевые результаты

- **Кальнексин нужен и для базовой экспрессии CFTR-вариантов, и для эффективности корректора**, причём эффект **вариант-специфичен**: зависимость ответа на VX-445/VX-661 от присутствия CANX различается между вариантами.
- Клеточный контекст (шаперонный машинный) — модификатор фармакологического ответа, а не «общий множитель».

## Данные и код (открытость)

- Данные — сапплементы eLife/bioRxiv; код — github.com/schlebachlab (уточнить состав репозиториев при скачивании).

## Значение для нашей работы

1. Удвоивает открытый DMS-массив «CFTR-вариант → ответ на корректоры» (129 McKee + 232 здесь) для бонус-оси по модуляторам.
2. Прямое обоснование нашей оговорки о переносимости: ответ зависит от клеточной системы (у Toledano — HEK293T-репортер; у DESTOOP — органоиды; здесь — CANX-KO) → кросс-системная валидация в нашей постановке не избыточна, а необходима.
3. Демонстрация зрелости CFTR-DMS как метода — сатурационная карта CFTR в принципе собираема (её отсутствие — наше белое пятно и потенциал).

## Ограничения

- PME, не функция канала (как и McKee 2023).
- Только ±CANX и корректоры; нонсенс-вариантов в DMS-серии Schlebachа нет.

## CFTR в публичных бенчмарках — отсутствует (итог по блоку)

- **ProteinGym:** CFTR_HUMAN отсутствует среди 217 DMS-ассетов (проверено по `reference_files/DMS_substitutions.csv` репозитория ProteinGym) — CFTR попадает туда только через клинические ClinVar-варианты.
- **MaveDB:** CFTR-скорсетов нет (поиск по API пуст).
- **Livesey & Marsh** (31 DMS в оригинале; обновление 2025 — 51 предиктор, 819 белков): CFTR не входит.
- Следствие: готового CFTR-бенчмарка для readthrough- или модуляторного ответа не существует — собирать его (DMS Schlebachа + Toledano + внешние CFTR-наборы) придётся самостоятельно, и это самостоятельная часть вклада нашей работы.
