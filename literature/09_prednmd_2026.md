# predNMD (Berkeley), 2026 — random forest для NMD-предсказания всех stop-gain SNV
**Ссылка/DOI:** [bioRxiv 2026.06.20.733449](https://www.biorxiv.org/content/10.64898/2026.06.20.733449v1) · сайт: [compbio.berkeley.edu/proj/prednmd](https://compbio.berkeley.edu/proj/prednmd/) · **Статус:** препринт (июнь 2026) · **Роль для нас:** альтернативный NMD-признак для H4 (джоин к Toledano/ClinVar-панели)

## Библиография (для списка литературы)
predNMD. *bioRxiv*, 2026 (авторы — группа Berkeley compbio; уточнить).

## Что сделано (методы, датасет)
Random forest, обученный на 5 304 nonsense-вариантах из GTEx / TCGA / GEUVADIS / GREGoR. Предсказания выпущены для **всех возможных** stop-gain SNV генома.

## Ключевые результаты
Геном-шид покрытие предсказаний NMD-статуса; детали качества (метрики) — уточнить по препринту.

## Данные и код (открытость)
Предсказания доступны через сайт проекта; код — уточнить по препринту.

## Значение для нашей работы
Второй (независимый от NMDetective-AI) источник NMD-признаков: ансамбль/сравнение двух предикторов укрепит ablation-тест H4 (если оба скоры дают прирост — эффект не артефакт одного предиктора). Прогнозы на все возможные PTC закрывают и CFTR-панель 853 вариантов.

## Ограничения
Препринт; random forest на инженерных признаках vs RNA-LM у NMDetective-AI — вероятно ниже по качеству (проверить в препринте); обучающая выборка также в основном соматическая.
