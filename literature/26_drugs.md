# Справочник: препараты-индукторы readthrough (идентичность, класс, механизм)

Расшифровка всех аббревиатур дословно подтверждена по полному тексту Toledano et al. 2024 ([PMC11387191](https://pmc.ncbi.nlm.nih.gov/articles/PMC11387191/)). Составлено 09.11.2026 для постановки ML-задачи и презентации.

## Четыре механистических кластера (= основа категориальных признаков препарата)

1. **Рибосома (trans)**: gentamicin, G418, ELX-02
2. **Встраивание в мРНК (cis)**: clitocine, FUr
3. **Модификация тРНК**: DAP (FTSJ1, UGA-специфичный)
4. **Деградация факторов терминации**: SRI (eRF1), SJ6986 и CC-90009 (eRF3a)

## Значение для ML-постановки

- **Объединять в одной задаче корректно, но только с признаками препарата**: профили RT между препаратами разных MOA коррелируют слабо (clitocine vs SRI r=0.39) против одинаковых MOA (SRI vs SJ6986 r=0.93); предпочтения по стоп-кодонам класс-специфичны.
- **Признаки препарата (формализация):** (а) категориальные — MOA-кластер (4), мишень, класс соединения; (б) молекулярные дескрипторы RDKit из курэйтed SMILES (supplement Toledano; для ataluren/ELX-02 — из PubChem); (в) профиль сродства (корреляции RT, уже в работе).
- **Конфаунды:** clitocine — стабилизация РНК (часть «RT» может быть abundance); CC-90009 — подавление NMD (в композитной модели его эффект не сводится к readthrough).
- **Ataluren как zero-shot объект проблематичен**: нет в обучающих данных, мишень не установлена, RT-активность оспорена — честно пометить в тексте.
