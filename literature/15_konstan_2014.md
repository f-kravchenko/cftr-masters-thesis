# Konstan et al., 2014 — ataluren, Ph3 №1 при нонсенс-CF

**Ссылка/DOI:** Lancet Respir Med 2014, [PMC4154311](https://pmc.ncbi.nlm.nih.gov/articles/PMC4154311/) · **Статус:** рецензирована · **Роль для нас:** первый провал клинического readthrough без стратификации пациентов

## Библиография (для списка литературы)
Konstan MW, et al. Efficacy and safety of ataluren in patients with nonsense-mutation cystic fibrosis: results from a randomised, double-blind, placebo-controlled phase 3 trial. Lancet Respir Med. 2014. PMC4154311. *(точные страницы/том — уточнить)*

## Что сделано (методы, датасет)
Рандомизированное двойное слепое плацебо-контролируемое Ph3-исследование ataluren (PTC124) при нонсенс-мутационном МВ, 238 пациентов. Отбор — только по критерию «есть нонсенс-мутация», без стратификации по контексту стоп-кодона и второй аллели.

## Ключевые результаты
Первичная конечная точка не достигнута: разница ppFEV1 3.0% (95% CI −0.8…6.3; p=0.12). Пост-хок-анализ показал «эффект» в подгруппе без ингаляционного тобрамицина (+5.7%, p=0.0082) — результат, не подтверждённый впоследствии подтверждающим исследованием (см. `16_act_cf_2020.md`).

## Данные и код (открытость)
Клинические данные недоступны; только публикации/регистрации.

## Значение для нашей работы
Ключевой аргумент постановки: попытка лечить «всех нонсенс-пациентов подряд» без предсказания ответа провалилась. Ataluren отсутствует в датасете Toledano — наш leave-one-drug-out (H2) — прямой ответ на вопрос «кому из пациентов он мог бы помочь».
