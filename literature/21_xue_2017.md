## Что сделано (методы, датасет)

- Исследование спектра аминокислот, вставляемых при подавении терминации на клинически значимых нонсенс-вариантах CFTR — **G542X и W1282X** (два самых частых нонсенс-PTC при муковисцидозе).
- Метод: аналитика вставки на уровне пептида (масс-спектрометрия; детали протокола — уточнить по полному тексту).

## Ключевые результаты

- **W1282X вставляет Leu / Cys / Trp** — несколько near-cognate тРНК конкурируют за стоп-кодон, спектр вставки не единичный.
- Вставляемые аминокислоты при G542X также охарактеризованы (соотношения — уточнить по тексту).
- Вывод для нас: идентичность вставки — свойство конкретного стоп-кодона/контекста, а не случайность → в принципе предсказуема.

## Значение для нашей работы

1. Фундамент для H5: известные «правила вставки» (UGA → W/R/C; UAA/UAG → Q/K/Y — сводка из Bhat 2025) + конкретные спектры для W1282X/G542X.
2. W1282X есть в наших данных Toledano (RT 2.2%, лучший SJ6986) — можно сопоставить предсказание вставки с измеренным RT.
3. Прямое указание, что функция восстановленного белка зависит от того, **какая** аминокислота встала (например, Trp на месте 1282 ≠ Leu по эффекту на домен NBD2).
