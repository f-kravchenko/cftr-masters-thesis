# Lindeboom et al., 2019 — NMDetective: предсказание NMD-статуса PTC
**Ссылка/DOI:** [PMC6858879](https://pmc.ncbi.nlm.nih.gov/articles/PMC6858879/) · данные: [figshare 10.6084/m9.figshare.7803398](https://figshare.com/articles/dataset/NMDetective/7803398) · **Статус:** рецензирована, Nat Genet (том/страницы — уточнить) · **Роль для нас:** NMD-признак для H4 (join к Toledano)

## Библиография (для списка литературы)
Lindeboom R. G. H., et al. NMDetective. *Nature Genetics*, 2019. (полный список авторов и том — уточнить)

## Что сделано (методы, датасет)
Модель/набор правил для предсказания, будет ли патогенный PTC элиминирован NMD. Подход — интерпретируемые правила/дерево решений на основе признаков транскрипта: позиция PTC относительно последнего экзон-экзонного соединения, длина 3'UTR и др. Обучено на данных allele-specific expression. Даёт **бинарный** NMD-статус.

## Ключевые результаты
Правила положения PTC относительно последнего экзон-экзонного соединения (классическое «50-нт правило») и длина 3'UTR объясняют значительную часть вариации NMD-эффективности; модель применима к любому stop-gain варианту генома.

## Данные и код (открытость)
Открыто: датасет на figshare, треки в UCSC Genome Browser.

## Значение для нашей работы
Источник NMD-признака для композитной модели `RT × NMD-escape` (H4): можно приjoin'ить скоры к вариантам Toledano и к CFTR-панели по координатам/транскрипту. Бинарность — ограничение: количественную эффективность NMD даёт уже NMDetective-AI (2026).

## Ограничения
Бинарный выход (NMD-чувствителен/нет), а не количественный; правила, а не ML в современном смысле; для нашей задачи — признаки уровня транскрипта, не локального контекста.
